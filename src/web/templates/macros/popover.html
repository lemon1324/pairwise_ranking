{%- endmacro %} {# popover_actions(actions) actions a sequence of mappings, each with: action the name posted back, e.g. "retire". label the words on the cell. key the shortcut's legend, as drawn: "R", "Del", "↵". shortcut the same shortcut written as UI Events key values: "R", "Delete", "Enter", "PageUp PageDown". Wanted whenever the legend is a glyph or an abbreviation, which is most of them. url optional; an hx-get for the fragment this action opens. href optional; makes the cell a link to this address instead of a button. For an action that leaves the page - the register's Open and Download - because a button that navigates is one whose middle click, whose "open in new tab" and whose status bar all do nothing. An action has one or the other, never both. form optional; the id of a POST form elsewhere in the callout that this cell submits. For an action that changes the project at once, with nothing to fill in - Items' Retire. The form is the caller's to draw, *outside* this strip: the phone rule that widens an odd last cell counts the strip's children. A strip of equal cells sharing 1px ink gaps. The shortcut is declared with aria-keyshortcuts as well as drawn, so the legend is a picture of something assistive technology has actually been told about - but the two are different strings. ARIA reads key *values*, and "↵" or "Del" names no key at all, so the legend and the declaration are separate arguments. A legend that is already a key value - a bare letter or digit - stands for both; anything else without a `shortcut` is drawn and left undeclared rather than declared wrong. `tb_sheet` in title_block.html spells its own the same way. The same value goes on `data-sheet-key`, which is what actually makes the key work: sheet.js presses the button when that key is pressed. So the legend on the cell, what assistive technology is told, and what the key does are one declaration, and a screen that draws a key it has not wired is not possible here. A cell with no declarable shortcut gets neither attribute. #} {% macro popover_actions(actions) -%}
