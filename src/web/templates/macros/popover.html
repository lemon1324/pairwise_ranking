Wanted whenever the legend is a glyph or an abbreviation, which is most of them. url optional; an hx-get for the fragment this action opens. A strip of equal cells sharing 1px ink gaps. The shortcut is declared with aria-keyshortcuts as well as drawn, so the legend is a picture of something assistive technology has actually been told about - but the two are different strings. ARIA reads key *values*, and "↵" or "Del" names no key at all, so the legend and the declaration are separate arguments. A legend that is already a key value - a bare letter or digit - stands for both; anything else without a `shortcut` is drawn and left undeclared rather than declared wrong. `tb_sheet` in title_block.html spells its own the same way. #} {% macro popover_actions(actions) -%}
