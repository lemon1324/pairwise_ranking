{# The scaffolding row callout: what a screen's fragment has to look like. Scaffolding for phase 5a, deleted with the rest of the placeholder. The actions do nothing; the point is the shape. A callout fragment is the callout element and nothing around it - no wrapper, no host - because it is swapped into `#row-callout`, which base.html keeps outside every region a screen swaps. The folding engine finds `.bom-callout` inside that host, places it beside the selected row's find number and draws the leader. Each action carries `data-sheet-key`, which the popover macro writes from the same value it declares to assistive technology: the engine presses the button when that key is pressed, so the shortcut, the legend on the cell and the thing that happens are one declaration and cannot drift apart. There is deliberately no Cancel here.
